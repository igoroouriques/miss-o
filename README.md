## ✨ Sobre o projeto

Um projeto pessoal de front-end que conta uma história em etapas: barra de progresso, linha do tempo, conquistas, uma carta que se abre com um toque e um final interativo. Tudo foi pensado para funcionar bem no celular, que é onde a maioria das pessoas vai abrir.

O foco foi a experiência: ritmo, animações discretas, trilha sonora e detalhes que só aparecem para quem explora.

## 🧩 Destaques

- **Fluxo em etapas** com navegação para frente e para trás e barra de progresso animada.
- **Linha do tempo e cartões de conquistas** feitos só com CSS.
- **Trilha instrumental gerada no navegador** com a Web Audio API: acordes sintetizados, filtro e fade, sem arquivo de áudio.
- **Players de áudio próprios**, com barra de posição e controle de reprodução, sem depender de serviços externos.
- **Galerias com abas** navegáveis por teclado (setas, Home e End).
- **Efeitos pontuais**, como confete e revelação gradual de texto, que respeitam a opção "reduzir movimento" do sistema.
- **Acessibilidade:** foco visível, foco levado ao título de cada etapa, rótulos ARIA e contraste revisado.
- **Responsivo e mobile-first**, com tema escuro.

## 📁 Estrutura

```
surpresa/
├── index.html    # página completa: HTML, CSS, JS e mídias embutidas
└── .nojekyll     # evita o processamento do Jekyll no GitHub Pages
```

O projeto é de **arquivo único**: não há build, bundler nem instalação de pacotes.

## 🚀 Como rodar localmente

```bash
# 1. Clone o repositório
git clone https://github.com/igoroouriques/surpresa.git

# 2. Entre na pasta
cd surpresa

# 3. Abra o index.html no navegador
```

Também dá para servir com qualquer servidor estático, por exemplo:

```bash
npx serve .
```

## 🌐 Publicação

O site é publicado com **GitHub Pages**, direto da branch `main`, na raiz do repositório.

## 📱 Compatibilidade

Testado em navegadores modernos baseados em Chromium. Para o áudio funcionar melhor no celular, abra o link direto no Chrome ou no Safari, e não pela prévia de aplicativos de mensagem.
